# Dark Patterns, Generated

Slides and evidence for a 15-minute tbd/con talk. The talk is built on an eight-run Google
Stitch pilot that tests whether a prompt-to-UI generator invents facts and persuasion cues
when it is told not to.

**Start with [`REPORT.md`](REPORT.md).** It covers the method, all results, what the pilot
does and does not show, and corrections to the deck.

- Protocol and exact prompts: [`stitch-plan.md`](stitch-plan.md)
- Per-run scores and verbatim quotes: [`runs/results.md`](runs/results.md)
- Screenshots: [`runs/screenshots/`](runs/screenshots/)
- Deck: [`presentation.html`](presentation.html)
